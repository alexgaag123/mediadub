# Эксперименты MediaDub

Сравнили распознавание текста и диаризацию на материале сериалов. Для каждого эксперимента зафиксировали, что менялось, что наблюдали при прослушивании и как собрать браузерный отчёт.

| Эксперимент | Что сравнивали | Наблюдение |
| --- | --- | --- |
| [Parakeet v2 и v3](parakeet/README.md) | Две версии ASR на аудио первого сезона «Любовь, смерть и роботы». Интервалы говорящих одинаковые | По просмотренным сценам v3 лучше распознавал слова. Его использовали в прогоне «Друзей» |
| [Nemotron 3.5 Transcribe](nemotron35/README.md) | Текст и ID модели против MediaDub на «Любовь, смерть и роботы». Дополнительно проверили русскую речь на фрагменте «Чернобыля» | На отдельных фразах текст понравился больше. Встречались пропуски речи и менее стабильные ID |
| [pyannote Community‑1](pyannote_community1/README.md) | Две диаризации на одних словах Parakeet v3 в S01E01 «Любовь, смерть и роботы» | Сглаживание улучшило отдельные переключения. По прослушиванию оставили диаризацию MediaDub |

В сравнениях «Любовь, смерть и роботы» выводы основаны на прослушивании и расхождениях в HTML. Количественные результаты на «Друзьях» и исторический тест DER/SER на AVA‑AVD описаны в [чекпоинте по диаризации](../diarization/README.md).

**Как читать отчёты.** Текст подсвечивается при расхождении, а рамка на совпавшем слове отмечает разный ID. Кнопка воспроизведения открывает нужный интервал. Номера говорящих локальны для каждого прогона. Там, где сравниваем две диаризации, отчёт сопоставляет их ID по совпадению во времени. Оценка качества требует эталона.

Для запуска из переносимой сборки скопируй папку `experiments/` целиком в её корень и выполняй команды оттуда. Скрипты используют локальные веса и результаты MediaDub, а HTML пишут рядом с результатами.
